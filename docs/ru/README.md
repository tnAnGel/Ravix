# Документация Ravix

[English](../en/README.md) · **Русский** · [中文](../zh/README.md)

</div>

---

Ravix — self-hosted панель управления почтовым сервером на Linux. Она
устанавливает и обслуживает Postfix, Dovecot, Rspamd, OpenDKIM и Certbot на том
же хосте, где работает сама, и даёт дашборд для доменов, ящиков, состояния DNS,
доставляемости и рассылок.

> ⚠️ **Ravix 0.1 — пре-релиз, не готовый к продакшену без доработки.** Бэкенд
> работает от root, CORS по умолчанию открыт, ограничения на попытки входа нет.
> Прочитайте [Безопасность](security.md) перед тем, как выставлять панель в
> интернет.

## Соглашения

- Команды с `sudo` выполняются от root на почтовом хосте.
- `example.com` — всегда заглушка, подставляйте свой домен.
- `panel.example.com` — имя хоста, на котором отдаётся *панель*; обычно оно
  **не** совпадает с почтовым именем хоста.
- Пути даны для установки по умолчанию — см. [Конфигурацию](configuration.md),
  если вы их переопределяли.
